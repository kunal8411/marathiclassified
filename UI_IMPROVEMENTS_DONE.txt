📋 AD VISIBILITY FIX
═══════════════════════════════════════════════════════════════════════════

PROBLEM SOLVED:
❌ "I posted an ad but it's not visible"

SOLUTION:
✅ Ads start in "pending" status (requires admin approval)
✅ Only "active" ads visible on home page
✅ Users can see their pending ads in Profile > My listings
✅ Admin approves → Ad becomes "active" → Visible to all

ADMIN WORKFLOW:
1. Login as admin (admin@marathiclassifieds.com / Admin@12345)
2. Go to /en/admin
3. See "Pending Ads: 5" on dashboard
4. Click "Moderate Ads"
5. Review your test ad
6. Click "Approve"
7. Go back to home page
8. Your ad now appears!
