📱 WHAT IS THIS APP?
═══════════════════════════════════════════════════════════════════════════════

A production-ready classified ads platform (like OLX) where users can:

  🛍️  Post & Browse Ads
      • Cars, bikes, phones, properties, jobs, services
      • Search by category, location, price
      • View detailed product information

  💬 Chat & Communicate
      • Real-time messaging between buyers/sellers
      • Message history & persistence
      • Seller information & contact details

  ⭐ Rate & Review
      • Rate sellers based on transactions
      • Build seller reputation
      • See buyer/seller ratings

  🌍 Multi-Language
      • English & Marathi support
      • Toggle language easily
      • Dark mode available

  🔐 Security
      • Email/password authentication
      • OTP verification
      • Google OAuth login option
      • Admin moderation system


═══════════════════════════════════════════════════════════════════════════════

🎯 USER JOURNEYS
═══════════════════════════════════════════════════════════════════════════════

BUYER:
  1. Browse homepage (quick search filters)
  2. Search for items (car, phone, etc.)
  3. View ad details with images
  4. Message seller directly
  5. Arrange meetup
  6. Rate seller

SELLER:
  1. Sign up / Login
  2. Post new ad with images & description
  3. Ad goes to Admin approval
  4. Ad becomes visible once approved
  5. Receive messages from buyers
  6. Chat & negotiate
  7. Build rating/reputation

ADMIN:
  1. Approve/reject pending ads
  2. Review & moderate user reports
  3. Ban users if needed
  4. View analytics & statistics

🔑 IMPORTANT TO KNOW
═══════════════════════════════════════════════════════════════════════════════

✅ DO:
  • Test on mobile (F12 → Device emulation)
  • Run npm run build before pushing
  • Keep TypeScript strict mode
  • Use environment variables for secrets
  • Follow existing code patterns
  • Document major changes
  • Commit with clear messages

❌ DON'T:
  • Commit .env.local to Git
  • Hardcode secrets or API keys
  • Break existing routes/APIs
  • Use "any" type in TypeScript
  • Skip linting/build checks
  • Ignore error messages
