🚀 DEPLOYMENT STEPS
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Test Build Locally
  $ npm run build
  ✅ Should complete without errors

STEP 2: Push to GitHub
  $ git add .
  $ git commit -m "feat: production deployment"
  $ git push origin main

STEP 3: Connect to Netlify
  1. Go to https://app.netlify.com
  2. Click "Add new site" → "Import an existing project"
  3. Select GitHub
  4. Choose your repository
  5. Build settings:
     - Build command: npm run build
     - Publish directory: .next
  6. Click "Deploy"
  ⏳ Build will fail (normal - no env vars yet)

STEP 4: Add Environment Variables
  1. Go to "Site settings" → "Build & deploy" → "Environment"
  2. Click "Edit variables"
  3. Add ALL variables from list above
  4. Save

STEP 5: Trigger Rebuild
  1. Go to "Deploys" tab
  2. Click "Trigger deploy" → "Deploy site"
  3. Wait 3-5 minutes for build

STEP 6: Verify Live Site
  ✅ Visit: https://your-site.netlify.app
  ✅ Test homepage
  ✅ Try signing up (should receive OTP email)

📝 HOW TO GET SECRETS
═══════════════════════════════════════════════════════════════════════════════

JWT_ACCESS_SECRET:
  $ node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
  (Run 3 times for all 3 JWT secrets)

RESEND_API_KEY:
  1. https://resend.com/dashboard
  2. Click "API Keys"
  3. Create new key
  4. Copy (starts with re_)

MONGODB_URI:
  1. https://www.mongodb.com/cloud/atlas
  2. Click cluster
  3. Click "Connect"
  4. Copy connection string

TWILIO:
  1. https://www.twilio.com/console
  2. Find Account SID, Auth Token, Phone

PUSHER:
  1. https://dashboard.pusher.com
  2. Select your app
  3. Find App ID, Key, Secret

CLOUDINARY:
  1. https://cloudinary.com/console
  2. Find Cloud Name, API Key, Secret

GOOGLE:
  1. https://console.cloud.google.com
  2. Create OAuth 2.0 Client ID
  3. Redirect URI: https://your-domain.netlify.app/api/auth/callback/google

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Build Failed?
  → Check Netlify build log
  → Verify all env variables set
  → Ensure MongoDB connection string correct

Database Connection Error?
  → MongoDB Atlas → IP Whitelist → Allow all (0.0.0.0/0)
  → Or add Netlify specific IPs

Email Not Sending?
  → Check RESEND_API_KEY is correct
  → Verify domain in Resend dashboard
  → Check Resend logs for errors
  → Use RESEND_FROM_EMAIL with verified domain

Site Shows Error?
  → Open browser console (F12)
  → Check for specific error message
  → Check Netlify function logs
  → Verify all env vars in Netlify UI
